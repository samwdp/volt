# Shared Markdown Pipeline with in-buffer Pretty

Markdown shows up in file buffers, hover, and ACP output. We use one Markdown Pipeline for highlight + Markdown Pretty on all of those surfaces (buffer and ephemeral-string entry points), guided by render-markdown.nvim: master enable (default on for markdown) plus per-buffer toggle, cursor-line and Visual-selection Anti-conceal, and a user-package treesitter-node→icon map. Inline images replace the source line (local/https/data, async disk cache; no SVG inline); tables keep today’s pretty path gated by the same enable/Anti-conceal. Hybrid paint: overlays when height stays 1:1, display projection when it does not. Forced Language lets plugin buffers stick `markdown` without a path. Pretty Kill-switch exists as config with default off. We rejected a separate preview pane, strict whole-buffer pretty/raw only, and per-surface renderers.
